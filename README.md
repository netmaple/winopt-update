# WinOpt 系统优化工具

Windows 10 / 11 一键优化工具，单文件绿色运行，无需安装、不写注册表。

## 产品特性

- **一键优化 / 一键还原**：所有改动可完整回退，不留残余
- **垃圾清理**：系统缓存、更新残留、日志、临时文件，支持一键全部清理
- **隐私与安全**：关闭遥测与数据上报，收紧默认权限
- **系统服务与计划任务**：按需精简，降低待机资源占用
- **软件免疫**：关键目录防误删占位，可随时还原
- **内置更新**：启动后后台静默比对版本，有新版本自动提示，一键升级并自动重启

## 适用范围

- 支持 Windows 10 / Windows 11
- 单文件运行，无需安装依赖
